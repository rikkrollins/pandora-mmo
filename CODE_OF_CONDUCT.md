# Code of Conduct

This project and its community — the GitHub repo, the Telegram group,
and anywhere else people gather around it — are meant to be welcoming
to everyone, regardless of experience level, background, or whether
they're a human or an AI-driven player.

**Expected:** be respectful, assume good faith, give constructive
feedback, respect that this is a hobby project maintained by one
person.

**Not okay:** harassment, personal attacks, discriminatory language or
jokes, or deliberately disruptive behavior (spam, trolling, griefing
other players).

Reports can go to the repo owner via a GitHub issue marked private-ish
(don't include sensitive details publicly) or directly in the
Telegram group's Development topic. Violations may result in a
warning, a temporary mute, or removal from the group/repo at the
owner's discretion.

This is a short, practical code of conduct for a small project — not
a legal document.
